# 截图目录

README 顶部和正文会引用这里的 5 张图，**文件名不要改**，改了就显示不出来。

| 文件 | 拍的是什么 | 用在哪 |
|---|---|---|
| `1-setup.jpg` | 安装完自动打开的配置页：显示手机该访问的地址，两种用法各一段说明 | 「安装」小节 |
| `2-phone.jpg` | 手机网页首屏：电脑剪贴板 + 发送输入框 | 顶部第一屏 |
| `3-share-sheet.jpg` | iPhone 分享面板，动作列表里能看到「发到电脑」 | 「方式二：快捷指令」 |
| `4-pc-inbox.jpg` | Windows 资源管理器里的收件箱，一个文件处于选中状态 | 顶部第二组 |

## 维护约定

- 每张图在 README 里都带 `alt` 文案和一行 `<sub>` 说明，换图时顺手核对描述还准不准
- 手机截图统一 1179×2556（iPhone 自带截图），电脑截图框选窗口即可
- 单张控制在 450KB 以内；改完确认 README 里引用的文件名没跟着变

## 隐私检查

图片会进公开仓库，换图前扫一眼：文件名、IP、剪贴板内容有没有不能公开的东西。
现在 `1-setup.jpg` 里的 IP 已打码；`4-pc-inbox.jpg` 能看到完整收件箱列表，自己判断要不要换。
