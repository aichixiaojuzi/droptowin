## 维护约定

- **尺寸按显示宽度定，不是按原图大小**：`![]()` 不会缩图，图片按实际像素宽度显示。
  现在并排的两张各 400px，通栏的 640px，配文里的 280–300px；任何一张别超过 660px，
  否则本地查看器会横向溢出、一页显示不全
- 每张图在 README 里都带 `alt` 文案，换图时顺手核对描述还准不准
- 手机截图统一 1179×2556（iPhone 自带截图），压之前先裁掉状态栏之外的多余部分
- 出图参数：LANCZOS 缩放 + JPEG quality 86 + optimize + progressive，单张控制在 100KB 内
- 改完确认 README 里引用的文件名没变

## 隐私检查

图片会进公开仓库，换图前扫一眼：文件名、IP、剪贴板内容有没有不能公开的东西。
现在 `1-setup.jpg` 里的 IP 已打码；`4-pc-inbox.jpg` 能看到完整收件箱列表，自己判断要不要换。
